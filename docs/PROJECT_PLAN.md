# LumenVale: City of Knowledge — Master Project Plan

## Architecture
- **Student Client**: Unreal Engine 5.8 (`EduGame.uproject`)
- **Teacher Platform & Authoritative Backend**: Next.js 16 + React 19 + Zod 4 + Neon PostgreSQL (`teacher/`)
- **3D Asset Production**: Blender 5.3 Python CLI + PBR Materials
- **Source Control**: `AnasAbuJamal/myFirstRepostory`, branch `unreal-lumenvale-development` (`main` and `market-office-first-person` preserved untouched)

## Execution Priorities
1. Priority 1: Project foundation, hardware audit, shared contracts, persistent docs.
2. Priority 2: Complete 8-district city environment (Blender 5.3 PBR assets -> UE 5.8 `L_LumenVale_City`, daylight lighting, NavMesh, collisions, visual inspection).
3. Priority 3: Core student gameplay (Enhanced Input, `BPI_Interactable`, doors, Executive Office & Computer, City Phone 8 apps, 12-level Reading, Spaced-Repetition Vocabulary, Save/Recovery).
4. Priority 4: Academic platform (`teacher/` Next.js 16 + Neon PostgreSQL authoritative APIs, gradebook/GPA/transcripts, 11-schema JSON importer & AI prompt generator).
5. Priority 5: Academic gameplay integration (School, Library, Courses, Exams, GPA, Careers, Quran memorization live sync).
6. Priority 6: Economic systems (Banking, Property, Businesses, Employees, Inventory, Production).
7. Priority 7: Advanced simulation (NPCs, Traffic, Transportation, Career & Industrial expansion).
8. Priority 8: QA, automated tests, visual inspection, Intel Arc performance profiling, security review.
